# Experimental Notebooks

This directory contains Jupyter notebooks demonstrating the research pipeline:

1. `01_preprocessing_and_wavelets.ipynb`: Savitzky-Golay baseline drift removal and Daubechies-2 wavelet thresholding.
2. `02_feature_extraction_pipeline.ipynb`: 140-dimensional feature extraction across 14 channels.
3. `03_model_benchmarking_and_evaluation.ipynb`: Comparative validation analysis (SD vs. SI) across all models.
