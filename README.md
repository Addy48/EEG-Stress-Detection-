# Inter-Subject Variability in EEG-Based Stress Detection

## Overview

This repository investigates machine learning classification of cognitive stress using 14-channel EEG recordings from the SAM-40 dataset under both subject-dependent and subject-independent validation protocols.

### Objectives
- Benchmark classical machine learning algorithms on EEG stress detection.
- Quantify the generalization gap between subject-dependent (SD) and subject-independent (SI) cross-validation.
- Analyze the impact of signal preprocessing, wavelet denoising, and statistical feature extraction.

### Directory Structure
